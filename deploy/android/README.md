# THEDAD для Android — Google Play и RuStore

Приложение для Android — это тот же сайт thedad.ru, упакованный в
**Trusted Web Activity** (TWA): полноэкранное окно Chrome без адресной строки,
с иконкой на рабочем столе и в магазине. Код не переписывается, обновления
приходят вместе с сайтом — пересобирать APK нужно только когда меняется
иконка, название или версия для магазина.

Всё, что здесь делается, — на вашем компьютере: нужен ваш ключ подписи, а он
никогда не должен попадать в репозиторий.

## Что понадобится

- **JDK 17** и **Android SDK** — Bubblewrap предложит скачать их сам при первом
  запуске, соглашайтесь.
- **Node.js** (уже есть).
- **Bubblewrap:** `npm install -g @bubblewrap/cli`
- Для Google Play — аккаунт разработчика (разовый взнос $25).
  Для RuStore — аккаунт разработчика на console.rustore.ru (бесплатно).

## 1. Ключ подписи — один раз и навсегда

```bash
cd deploy/android
keytool -genkeypair -v -keystore thedad-release.keystore -alias thedad \
  -keyalg RSA -keysize 2048 -validity 10000
```

Придумайте пароль и **сохраните файл `thedad-release.keystore` и пароль в
надёжном месте вне репозитория** (менеджер паролей + резервная копия). Потеря
ключа означает, что обновить приложение в RuStore будет нельзя — только
выпустить новое под другим именем. (В Google Play при включённой подписи
приложений Google ключ загрузки можно восстановить через поддержку, но лучше
не проверять.)

`.gitignore` в этой папке уже не пускает ключи в git.

## 2. Связать сайт и приложение

Без этого приложение откроется с адресной строкой браузера сверху — Android
должен убедиться, что приложение и сайт принадлежат одному владельцу.

Узнайте отпечаток ключа:

```bash
keytool -list -v -keystore thedad-release.keystore -alias thedad | grep SHA256
```

Скопируйте `assetlinks.template.json` в `public/.well-known/assetlinks.json`
в корне репозитория и вставьте отпечаток вместо `ВСТАВЬТЕ_SHA256_ОТПЕЧАТОК_КЛЮЧА`
(формат `AB:CD:…`, 32 пары через двоеточие). Закоммитьте и дождитесь выкладки
сайта. Проверка — в браузере должен открыться JSON:

```
https://thedad.ru/.well-known/assetlinks.json
```

**Google Play:** если включена подпись приложений Google Play (по умолчанию
включена), Google переподписывает сборку своим ключом. Тогда в `assetlinks.json`
нужен **и** отпечаток из Play Console (Настройка → Целостность приложения →
Подпись приложений → SHA-256) — добавьте его вторым элементом в
`sha256_cert_fingerprints`.

## 3. Собрать

```bash
cd deploy/android
bubblewrap build
```

Bubblewrap возьмёт настройки из `twa-manifest.json` (пакет `ru.thedad.app`,
цвета, иконка с сайта) и попросит пароль ключа. Результат:

- `app-release-bundle.aab` — для Google Play;
- `app-release-signed.apk` — для RuStore и для установки напрямую.

Поставить на свой телефон для проверки: включить «Для разработчиков → Отладка
по USB», подключить телефон и `bubblewrap install`.

## 4. Опубликовать

**Google Play** (play.google.com/console):

1. Создать приложение, заполнить карточку: описание, скриншоты телефона,
   иконка 512×512, ссылка на политику конфиденциальности —
   `https://github.com/uyellowline/thedad-releases/blob/main/PRIVACY.md`.
2. Раздел «Безопасность данных»: данные не собираются и не передаются
   (всё хранится на устройстве); если включена копия в Google Диск —
   указать, что по желанию пользователя данные шифруются и передаются в его
   собственный аккаунт Google.
3. Загрузить `.aab` в закрытое тестирование.

> **Важно для новых личных аккаунтов:** Google требует закрытого тестирования
> минимум с 12 тестировщиками в течение 14 дней, прежде чем открыть выпуск в
> продакшен. Начинайте раньше, чем нужен релиз.

**RuStore** (console.rustore.ru):

1. Создать приложение, загрузить `.apk`, карточку и политику.
2. Модерация обычно занимает несколько рабочих дней.

## 5. Обновления

Сам сайт обновляется как обычно — пересобирать APK не нужно, пользователи
увидят новую версию при следующем открытии.

Пересобирать нужно, если меняются иконка, название, цвета или когда магазин
требует повысить целевой уровень Android. Тогда в `twa-manifest.json`
увеличить `appVersionCode` на 1 (и `appVersionName` по желанию) и снова
`bubblewrap build`.

## Что приложение умеет и чего нет

Работает всё, что работает на сайте: офлайн, данные на устройстве, прогноз,
уведомления, пока приложение открыто. Как и у сайта, напоминания при
полностью закрытом приложении не приходят — для этого нужен push-сервер или
Telegram-бот (см. `docs/AUDIT-2026-09.md`, идея 8).

Если на телефоне Chrome, данные приложения и данные сайта thedad.ru в Chrome —
**общие**: TWA работает внутри Chrome и пользуется его хранилищем для этого
сайта. Кто уже пользовался сайтом, после установки приложения увидит свои
данные на месте.
