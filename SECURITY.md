# Политика безопасности

## Поддерживаемые версии

Обновления безопасности выпускаются для последнего минорного релиза в ветке `main`.

## Сообщить об уязвимости

Пожалуйста, **не открывайте публичный issue** для уязвимостей.

Напишите приватно на **<your-email@example.com>** с темой `SECURITY` и опишите:

- тип уязвимости и затронутый компонент;
- шаги воспроизведения;
- потенциальное влияние.

Мы постараемся ответить в течение 72 часов и согласовать сроки раскрытия.

## Модель безопасности THEDAD

- Приложение **local-first**: по умолчанию пользовательские данные не покидают устройство; подключаемые сервисы описаны в политике конфиденциальности.
- Хранилище — SQLite (WASM) в IndexedDB браузера.
- Экспорт БД может быть зашифрован паролем (AES-GCM, ключ через PBKDF2, 250k итераций).
- Нет серверной части в ядре — соответственно нет серверных секретов в этом репозитории.
- При синхронизации по email пароль передаётся серверу, и сервер технически может вычислить ключ расшифровки. Это не модель защиты от оператора сервера. См. [описание сервера](server/README.md).

Если вы нашли способ утечки данных за пределы устройства в ядре — это критично,
сообщите как можно скорее.
