# Фаза G — Визуальная плотность («прототип → финал»)

Диагноз: функционал есть, но экраны выглядят как мокап из-за низкой плотности,
отсутствия иконок/тегов и «мёртвых» пустых состояний.

## Что делает вид прототипом

1. Today Focus растянут на всю ширину → пустота. Нужна 2-я колонка «Сводка дня».
2. Нет иконок у задач / привычек / событий.
3. Нет цветных тегов/бейджей (High Impact, 90 min, Energy Boost).
4. Привычки: серые пустые точки, обрезанные имена, их слишком много.
5. Пустые данные показаны буквально («0ч 0м», плоский график).
6. Нет Quick Capture и Upcoming Events.
7. Sidebar беднее эталона (Focus Mode-карточка, Daily Progress кольцо, аватар-фото).
8. Topbar без ряда quick-actions.

## План (по эффекту)

### G1 — Today Focus + Сводка дня (2 колонки) ⭐
Убрать пустоту вверху. Слева Today Focus, справа «Сводка дня» на наших Insights
(лучшее окно фокуса, тренд, прогноз) — это «AI Day Brief» без AI.

### G2 — Quick Capture виджет ⭐
Правая колонка: табы Задача/Заметка/Привычка + поле «Что на уме?» + быстрые кнопки.

### G3 — Upcoming Events виджет
Ближайшие дедлайны целей + задачи с датами, иконка + дата.

### G4 — Иконки и теги в списках ⭐
- Задачи: иконка по типу/блоку + цветной тег приоритета/контекста.
- Привычки: иконка в кружке + цветные заполненные галочки + ограничение показа (топ-8 + «ещё»).
- События: иконка категории.

### G5 — Topbar quick-actions ряд
Под поиском: Создать задачу (T) / Заметка (N) / Фокус (F) / Цель (G) / Quick Capture (Q).

### G6 — Sidebar обогащение
Focus Mode-карточка с ▶ + Daily Progress кольцо + аватар с инициалом крупнее.

### G7 — Живые пустые состояния
Вместо «0ч 0м» — осмысленные плейсхолдеры/CTA. Графики с базовой линией.

## Порядок
G1 → G2 → G4 → G3 → G5 → G6 → G7
