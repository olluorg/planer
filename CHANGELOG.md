# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование: [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — не выпущено

### Добавлено
- **Предупреждение «не успевает к сроку».** Если при нынешнем темпе цель к
  сроку не достигается, в уведомлениях появляется карточка с тремя выходами в
  цифрах: какой нужен темп, на когда сдвинуть срок, до скольки уменьшить цель.
  Не чаще раза в неделю на цель.
- **Быстрая запись снаружи.** Десктоп: `Ctrl+Shift+Пробел` из любой программы.
  Расширение: `td купить молоко` в адресной строке.
- **Копия в Google Диск из расширения** — раньше работала только в браузере и
  на десктопе.

### Изменено
- **Знакомство в три шага вместо девяти:** имя → одна цель числом → первая
  отметка. Тема, виджеты и профиль здоровья — позже, в настройках.
- Приложение открывается быстрее: виджеты и окна загружаются по требованию
  (на старте на 45% меньше кода, чем в 1.0-бете).

### Исправлено
- После входа в синхронизацию на новом устройстве первая же правка могла
  затереть скачанные данные.
- Импорт файла, который не является базой, ломал приложение.

## [1.0.0] — не выпущено

Первый публичный релиз.

### Добавлено
- Резервная копия в Google Диск: дамп шифруется на устройстве парольной фразой
  и кладётся в скрытую папку приложения (scope `drive.appdata`). Кольцо из
  5 копий, суточный автобэкап, восстановление на другом устройстве.
- Локальные автоснимки базы: 3 последних, создаются раз в сутки и перед
  миграциями, импортом и восстановлением. Раздел «Резервные копии» в Настройках.
- Десктопная версия для Windows (установщик и portable) с автообновлением.
- Экран ошибки вместо белого экрана: перезагрузка, скачивание резервной копии,
  копирование отчёта. Локальный журнал последних ошибок — ничего не отправляется.
- Тесты (vitest) на прогнозирование, повторяющиеся задачи и шифрование экспорта.

### Исправлено
- Даты считались в UTC: восточнее Гринвича «сегодня» до 03:00 указывало на
  вчерашний день, а повторяющиеся задачи не сдвигались на следующий день вообще.
- Установка PWA была сломана: в манифесте не было иконок с `purpose: "any"`,
  а второй, пустой манифест конфликтовал с основным.
- Service worker пытался закэшировать несуществующий путь, из-за чего падал
  весь предварительный кэш и приложение оставалось без офлайн-режима.
- Правки последних 250 мс перед закрытием вкладки могли потеряться.
- Приложение больше не открывает базу, созданную более новой версией, — раньше
  это молча теряло незнакомые поля.

- Страница «Цели» была нечитаема на экранах уже 1280px: колонка с карточками
  схлопывалась в нулевую ширину. Затрагивало все ноутбуки и телефоны.
- Шрифт Inter не загружался никогда: объявления ссылались на файлы, которых не
  было в сборке. Приложение всё это время рисовалось системным шрифтом.
- Напоминания в расширении не приходили пользователям восточнее UTC+7:
  утренняя проверка искала задачи вчерашней даты.
- При первом открытии сайта страница через секунду перезагружалась сама —
  посреди мастера первого запуска.
- Прямая ссылка на раздел (например, thedad.ru/goals) открывала страницу
  ошибки вместо приложения.
- Экранные дикторы не называли, какую задачу вы отмечаете или удаляете:
  у галочек, отметок привычек, кнопок удаления и переключателей не было имён.

### Изменено
- Расширение Chrome запрашивает доступ к сторонним API только при включении
  соответствующих функций, а не при установке.
- Обновление приложения ставится по кнопке, а не подменяет ассеты на лету.
- Установщик для Windows уменьшен примерно с 200 до 79 МБ.
- Погода больше не определяет местоположение по IP через сторонний сервис —
  только по явному разрешению геолокации.
- У новой цели вместо пустого графика написано, чего не хватает для прогноза.
- Появилась [документация для пользователей](docs/README.md).
- Приложение открывается быстрее: библиотека графиков загружается, только
  когда на экране появляется график (на старте на треть меньше кода).
- Установленная десктопная версия блокирует переход окна на сторонние сайты
  и выдаёт только нужные разрешения; во всех версиях действует политика
  безопасности содержимого (CSP).
