# Выкат беты для фокус-группы

Тестерам НЕ нужны нативные приложения: THEDAD — PWA, ставится на iPhone/Android/планшет/десктоп
кнопкой «Установить приложение» и работает офлайн.

Нужно две вещи: **раздать фронт** и (если хочешь синк между устройствами) **поднять sync-сервер**.

---

## 1. Sync-сервер (нужен только для синхронизации)

Требуется: хост с публичным IP + Docker, и домен (напр. `sync.thedad.ru`), A-записью указывающий на него.

```bash
# на сервере
git clone <репозиторий> && cd planer/server

export SYNC_DOMAIN=sync.thedad.ru
export POSTGRES_PASSWORD='<длинный случайный пароль>'

docker compose -f docker-compose.prod.yml up -d --build
```

Caddy сам получит и будет продлевать TLS-сертификат Let's Encrypt. Проверка:

```bash
curl https://sync.thedad.ru/health   # → {"ok":true}
```

Наружу открыты только 80/443. Postgres и сам сервер — внутри сети Docker.

**Почему обязательно HTTPS:** фронт раздаётся по https, и браузер заблокирует запросы к http-серверу
(mixed content). Без https синк у тестеров просто не заработает.

---

## 2. Фронт → GitHub Pages

Пайплайн уже настроен (`.github/workflows/deploy.yml`), домен — `thedad.ru` (`public/CNAME`).

**Один раз** пропиши адрес сервера, иначе в сборку попадёт `localhost` и синк не заведётся:

> GitHub → Settings → Secrets and variables → **Actions** → вкладка **Variables** → New variable
> `VITE_SYNC_SERVER_URL` = `https://sync.thedad.ru`

Дальше любой push в `main` (или ручной запуск workflow) собирает и публикует.

Без синка можно ничего не задавать — приложение полностью работоспособно локально на устройстве.

---

## 3. Что сказать тестерам

1. Открыть **https://thedad.ru** на телефоне или ПК.
2. Меню браузера → «Установить приложение» / «На экран Домой».
3. Пройти онбординг. Можно **пропустить выбор сфер** — тогда стартуешь с чистого листа.
4. Синхронизация (по желанию): Настройки → «Синхронизация устройств» → вход по email **или**
   создать хранилище и привязать второе устройство сканом QR-кода.
5. AI-коуч (по желанию): Настройки → «AI-коуч» → свой OpenAI-совместимый ключ.

Данные хранятся локально на устройстве; при синхронизации на сервер уходит только
зашифрованный на клиенте блоб — сервер не видит содержимое.

---

## Ограничения беты (говорить честно)

- **Уведомления** приходят, пока приложение открыто (вкладка или установленное PWA). Фоновой
  доставки при полностью закрытом приложении нет — нужен push-сервер.
- **Синхронизация**: побеждает последнее сохранение (last-write-wins). Одновременное
  редактирование на двух устройствах может перезаписать изменения. Для одного человека с
  2–3 устройствами это нормально.
- Нативных приложений (App Store / Play / часы) и интеграции с Apple/Google Health пока нет —
  см. роадмап экосистемы.
