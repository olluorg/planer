# Как создать свой виджет для THEDAD — гайд для обычных людей

Свой виджет — это **один текстовый файл** `.json`. Никакого программирования: ты описываешь,
*какие данные показать* и *как они должны выглядеть*, а приложение рисует всё само.
Поэтому чужой виджет безопасно импортировать: в нём нет кода, он не может украсть твои
данные или отправить что-то в интернет.

## Быстрый старт за 3 шага

1. Скопируй любой пример из этой папки (`docs/plugins/*.thedad-widget.json`) и открой в блокноте.
2. Поменяй `id` (латиницей, без пробелов), `name` и содержимое под себя.
3. В приложении: **Настройки → Плагины → «Импортировать .json»** (или в редакторе дашборда
   нажми плитку «+» → карточка «Импортировать виджет»). Потом добавь виджет на дашборд
   через ту же плитку «+», категория «Плагины».

Если в файле ошибка — приложение при импорте скажет, что именно не так.

## Устройство файла

```jsonc
{
  "schema": "thedad.widget/v1",        // всегда так
  "id": "my-widget",                   // уникальное имя: a-z, 0-9, дефисы
  "name": "Мой виджет",                // заголовок на карточке
  "author": "@ник",                    // необязательно
  "icon": "heart",                     // иконка: puzzle, flame, star, heart, dumbbell,
                                       // book, check, list, activity, target, calendar,
                                       // repeat, timer, trophy, sparkles, moon, sun, drop, brain
  "defaultSize": { "w": 6, "h": 5 },   // размер на сетке (ширина 2..12 колонок, высота 2..12 рядов)
  "source": { ... },                   // ОТКУДА данные — см. ниже
  "render": { ... }                    // КАК показать — см. ниже
}
```

## Откуда берутся данные (`source`)

### Вариант 1: твои данные из приложения (только чтение)

```jsonc
"source": {
  "collection": "tasks",          // tasks, habits, habitLogs, goals, healthLogs,
                                  // progress, reflections, timeEntries
  "range": "last-7-days",         // today | last-7-days | last-30-days | last-90-days | all
  "groupBy": "date",              // сгруппировать по дням (для графиков)
  "where": { "status": "done" }   // простой фильтр «поле = значение»
}
```

Виджет видит только эти коллекции и не может ничего в них менять.

### Вариант 2: свой контент прямо в файле (`static`)

Для рецептов, тренировок, чек-листов, цитат — просто список записей (до 500):

```jsonc
"source": {
  "static": [
    { "day": 1, "meal": "Завтрак", "title": "Овсянка", "desc": "…", "recipe": "…", "image": "/food/breakfast-01.jpg" },
    { "day": 1, "meal": "Обед",    "title": "Курица с гречкой", "desc": "…", "recipe": "…", "image": "/food/lunch-01.jpg" }
  ]
}
```

Имена полей придумываешь сам — на них ссылается `render` через `{{поле}}`.

## Как показать (`render`)

| type    | Что рисует | Главные поля |
|---------|------------|--------------|
| `stat`  | Одно большое число | `value`: `"count"` (количество) или имя числового поля (сумма) |
| `ring`  | Кольцо прогресса | `value`, `max` (что считать за 100%) |
| `list`  | Список строк | `label`: шаблон строки, напр. `"{{date}} · {{mood}}"` |
| `bar` / `line` | График по дням | `value` + `source.groupBy: "date"` |
| `table` | Таблица | `columns`: `["date", "title"]` |
| `cards` | Карточки с картинками | см. ниже |

### Карточки (`cards`) — как виджет питания

```jsonc
"render": {
  "type": "cards",
  "label": "{{title}}",     // заголовок карточки
  "text": "{{desc}}",       // краткое описание на лицевой стороне
  "detail": "{{recipe}}",   // обратная сторона — открывается по клику
  "image": "image",         // имя поля с картинкой
  "badge": "{{meal}}",      // маленькая плашка сверху («Завтрак»)
  "dayField": "day"         // если задано — показываются карточки текущего дня месяца
}
```

С `dayField` виджет сам листает меню: 1-го числа показывает записи с `day: 1`,
2-го — с `day: 2`, а если дней в наборе меньше, чем в месяце, — идёт по кругу.

### Картинки

- Только **локальные пути**: файл кладёшь в папку `public/` проекта (например,
  `public/food/breakfast-01.jpg`) и пишешь `"/food/breakfast-01.jpg"`.
  Ссылки на интернет запрещены — это защита от слежки.
- Рекомендуемый размер: **640×400 px**, JPG, до 200 КБ.
- Пока картинки нет, показывается заглушка 🍽 — виджет работает и без неё.

## Поделиться виджетом

Настройки → Плагины → кнопка выгрузки рядом с виджетом — получишь тот же `.json`,
который можно отправить другу. Он импортирует его у себя за пару кликов.

## Что виджеты НЕ могут (безопасность)

- Выполнять код, скрипты, формулы — файл описательный.
- Читать AI-ключ, настройки синхронизации, чужие разделы хранилища.
- Менять твои данные (только чтение).
- Ходить в интернет (в том числе за картинками).

## Примеры в этой папке

- `nutrition-month.thedad-widget.json` — «Правильное питание на месяц»: карточки
  завтрак/обед/ужин на каждый день, по клику — рецепт.
- `tasks-done-week.thedad-widget.json` — график закрытых задач за неделю.
- `focus-minutes-month.thedad-widget.json` — сумма секунд фокуса за 30 дней.
- `reflections-list.thedad-widget.json` — список рефлексий за неделю.
