# Картинки для виджета «Правильное питание на месяц»

Положи сюда JPG-файлы блюд. Имена — по блюдам (30 штук):

- `breakfast-01.jpg` … `breakfast-10.jpg` — завтраки
- `lunch-01.jpg` … `lunch-10.jpg` — обеды
- `dinner-01.jpg` … `dinner-10.jpg` — ужины

Соответствие простое: **день N использует блюда №(N по кругу из 10)** —
день 1 → `breakfast-01`, `lunch-01`, `dinner-01`; день 2 → `*-02`; … день 11 → снова `*-01`.
«День 1» — это день, когда виджет впервые открыт (не число месяца).
Полное соответствие блюд — в `docs/plugins/nutrition-month.thedad-widget.json`.

Рекомендуемый размер: **640×400 px** (соотношение 16:10), JPG, до 200 КБ.
Пока файла нет — виджет показывает заглушку 🍽, ничего не ломается.
