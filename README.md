## Что это

THEDAD — это инструмент, который связывает **цели → действия → результат → прогноз**.
Вы ставите цели, планируете задачи и привычки, отмечаете прогресс — а приложение
строит прогноз достижения с доверительным интервалом и показывает, опережаете вы
график или отстаёте.

Всё хранится локально в браузере через **SQLite, скомпилированный в WebAssembly**.
Нет аккаунтов, нет облака, нет слежки. Работает офлайн (PWA).

## Возможности

- **Дашборд-конструктор** — виджеты с drag-n-drop, несколько экранов («рабочих столов»)
  со своими раскладками и шаблонами (Минимум / Фитнес / Фокус / Цели).
- **Цели** — долго/средне/краткосрочные, подцели, метрика, дедлайн, карта прогресса.
- **Задачи** — приоритеты, тайм-блоки, теги, подзадачи, повторы; список, канбан-доска
  по стадиям (To do → В работе → Готово) и доска по приоритету; история изменений.
- **Привычки** — дневной/недельный трекинг, серии, цветные точки.
- **Прогноз** — линейная регрессия, EMA, Holt; 95% доверительный интервал; ETA; what-if.
- **AI-помощник** — составляет план (цель + задачи + привычки) из описания и отвечает
  на вопросы. Три пути: встроенный в Chrome Gemini Nano (бесплатно, офлайн), свой ключ
  OpenAI / Claude / Gemini, или локальная модель через Ollama (см. Docker ниже).
- **Здоровье** — калории с БЖУ и своей библиотекой продуктов, активность по MET-формуле,
  BMR-профиль, зарядка 7 минут (3 типа тренировок), конструктор рациона на месяц.
- **Focus Mode** — полноэкранный Deep Work: помодоро/таймер, задачи дня, звуковой
  микшер (дождь, океан, костёр…), YouTube-музыка и видеофоны.
- **Мини-плеер** — музыка и «атмосфера» продолжают играть вне фокуса; управление
  из системной панели воспроизведения (Media Session).
- **Живые обои** — видеофайл или YouTube как анимированный фон (стеклянные темы).
- **Геймификация** — XP, уровни, серии, лиги, достижения, daily quests, конфетти.
- **Аналитика, календарь, рефлексия, инсайты, шаблоны, плагины** (свои виджеты из
  JSON — [spec](docs/PLUGINS_SPEC.md)), импорт/экспорт (CSV, JSON, зашифрованный
  `.sqlite`, Markdown-отчёт).

## Установка

| Вариант | Как поставить |
|---|---|
| **Web / PWA** | Открыть сайт → меню аватара → «Установить приложение». Работает офлайн на телефоне и десктопе. |
| **Chrome-расширение** | Скачать `planer-extension.zip` из [Releases](../../releases), распаковать, `chrome://extensions` → Режим разработчика → «Загрузить распакованное». Открывается **вместо новой вкладки** (Chrome спросит подтверждение) — поиск прямо в топбаре. |
| **Windows (desktop)** | Установщик/portable из релизов репозитория `planer-desktop` (Electron). Установленная версия сама подтягивает обновления с GitHub. |
| **Self-host (Docker)** | `docker compose up -d` → приложение на `:8080` + локальный AI (Ollama + Gemma) на `:11434`. Модель скачивается автоматически. |

### Бесплатный AI в Chrome

Встроенный Gemini Nano работает **только в Chrome** на компьютере. Включение:
`chrome://flags/#prompt-api-for-gemini-nano` → Enabled,
`chrome://flags/#optimization-guide-on-device-model` → Enabled BypassPerfRequirement,
перезапуск, затем в THEDAD: Настройки → AI-коуч → «Скачать модель» (~1–2 ГБ, один раз).
Та же пошаговая инструкция есть в самом приложении (Настройки → «Как включить?» и в онбординге).
В других браузерах — свой ключ или Ollama.

### Self-host с локальным AI

```bash
git clone <репозиторий> && cd planer
docker compose up -d          # приложение :8080, Ollama :11434, Gemma тянется сама
```

В приложении: Настройки → AI-коуч → провайдер **«Ollama (локально)»** — готово, ключ не нужен.
Модель меняется переменной `OLLAMA_MODEL` (по умолчанию `gemma3:4b`). Python и ручная
настройка не нужны — Ollama сама скачивает и раздаёт модель по OpenAI-совместимому API.
Примечание: Gemini Nano в Docker не упаковывается (он часть Chrome) — локальный AI здесь
даёт Gemma через Ollama, что функционально эквивалентно.

## Быстрый старт (разработка)

```bash
# нужен Bun (https://bun.sh) или Node 18+
bun install
bun run dev        # http://localhost:5173
```

```bash
bun run build      # прод-сборка в dist/
bun run build:ext  # сборка Chrome-расширения в dist/
bun run preview    # локальный предпросмотр сборки
bun run lint       # tsc --noEmit
```

## CI/CD и подпись сборок

- **CI** (`.github/workflows/ci.yml`) — typecheck + build на каждый push/PR в `main`.
- **Deploy** (`.github/workflows/deploy.yml`) — push в `main` публикует веб-версию на
  GitHub Pages и прикладывает свежий `planer-extension.zip` (+ SHA-256) к GitHub Release.
- **Desktop** — собирается в репозитории `planer-desktop` (electron-builder → NSIS +
  portable), релиз с автообновлением через GitHub Releases.
- **Подпись:** расширение подписывает Chrome Web Store при публикации (для sideload
  подпись не нужна). Windows-установщик без купленного сертификата подписи покажет
  предупреждение SmartScreen — это нормально для OSS; сертификат (OV/EV) подключается
  в CI секретами `CSC_LINK`/`CSC_KEY_PASSWORD` без изменения кода. Целостность любой
  сборки можно проверить по `SHA256SUMS` из релиза.

## Данные приватны

Всё хранится в IndexedDB вашего браузера. Сетевых запросов с пользовательскими
данными нет. AI-ключи лежат только в localStorage устройства, запросы к провайдерам
идут напрямую (без промежуточных серверов). Встроенный Chrome AI и Ollama работают
полностью локально. Экспорт БД можно зашифровать паролем (AES-GCM + PBKDF2).
